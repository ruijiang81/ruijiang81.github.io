# ruijiang81.github.io

Personal academic website of Ruijiang Gao, Assistant Professor of Information Systems at the Naveen Jindal School of Management, UT Dallas. Built with Jekyll on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and served by GitHub Pages.

## Editing

- `_pages/about.md`: home page (bio, research, news, selected publications, awards, service)
- `_pages/publications.md`: full publication list
- `_pages/teaching.md`: teaching and student supervision
- `_pages/cv&contact.md`: CV link and contact details
- `_publications/`: abstract pages for working papers
- `_data/navigation.yml`: top menu
- `_config.yml`: site settings and author profile
- `files/cv/`: CV PDF

## Local preview

```
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.
